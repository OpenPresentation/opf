A name among logos (a plain text in the `logos` layout's picture region) is drawn as a wordmark: a tile of the pictures' proportions (5:2 when none is known), the pictures' frame in a mixed row, with the name centered in it, starting at 40 px and stepping down until it fits, so it reads beside the marks at one size in any row instead of small plain text between tiles. A row of pictures alone is unchanged.
