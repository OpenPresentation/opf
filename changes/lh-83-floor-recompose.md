LH-83 (output-changing for template slides whose layout sets a body role at the readability floor): when a layout template's composition sets text, a list, a table or the main part of a quote, code panel, metric or timeline at the readability floor, `composeSlide` composes the same blocks again as the automatic grid, with the layout record's design and composition, and keeps that result when its smallest body size is larger and it neither overflows nor breaks lines inside words more; otherwise the layout's result stands. The recomposed slide sets its headings above the body as an automatic slide does, has no `regions` or `headingAreas`, and reports `recomposed: { layoutSize, size }`; every block is still drawn, and the preview and the PPTX export draw it from core. A slide the layout fits above the floor, a slide with a block pinned to a region and `composeSlide(slide, { recompose: false })` keep the layout's composition. Of the 360 composition goldens, 20 overfull cases move (agenda-split, two-column, process, timeline, metrics, image-beside, chart-beside, table, table-beside, code and hero with long or many blocks), each from overflow or the floor to no finding; no gallery layout at its sample content changes.
