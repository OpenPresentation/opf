LH-127, LH-39, LH-128 (output-changing for slides with an inline unit, a metric whose figure wrapped, and a paginated paragraph): an inline metric unit follows its value as drawn, a `METRIC_UNIT_GAP` (0.12 em of the value's size, at least 8 px) after it. Without a host measurement the portable estimate is slack for a figure (about a fifth too wide for "2.4" at 120 px, so the unit floated a few characters away): a value written in digits, separators, signs and currency marks is now measured by a heavy-face advance table (`FIGURE_ADVANCES`) and its line takes that width, so an engine that centers or ends the line on its accepted width draws both where core expects; a value with a letter or a percent sign keeps the estimate, and a host measurement is used as before. A value of one word never wraps (`layoutMetric` option `figure`, default true): it is set on one line at the largest size of the type scale that holds it instead of split ("$1.24" over "M"). In a composition this is the guarded rule `metric-figure`, tried on top of the rules the guard keeps: a figure split across lines counts as unreadable like an overflow, so the slide may take the next smaller size for that figure (and only it, the sibling figures sharing one size) when it reads as well otherwise; `readsAsWell` no longer accepts an arrangement that newly splits a figure. `paginate` ends a page at the last sentence end that fits, wherever it falls, and moves a sentence that does not fit beside what the page holds whole to the next page when a page can hold it alone, so a continuation page no longer opens with a fragment such as "twenty."; a list marker ("2. ") is not a sentence end, and a sentence no page can hold is still split inside. A value's line height stays 1.22 (see the pull request).
