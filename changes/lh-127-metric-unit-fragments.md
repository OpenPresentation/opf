LH-127, LH-39, LH-128 (output-changing for slides with an inline unit drawn without a host measurement, a metric whose figure wrapped, and a paginated paragraph): an inline metric unit follows its value as drawn. Without a host measurement the portable estimate is slack for a figure (about a fifth too wide for "2.4" at 120 px, so the unit floated a few characters away); a value written in digits, separators, signs and currency marks is now measured by a heavy-face advance table (`FIGURE_ADVANCES`) and its line takes that width, so the unit sits one gap after it and an engine that centers or ends the line on its accepted width draws both where core expects; a value with a letter or a percent sign keeps the estimate, and a host measurement is used as before. A value of one word never wraps (`layoutMetric` option `figure`, default true): it is set on one line at the largest size that holds it instead of split inside the figure ("$1.24" over "M"), and composition takes that only through the new guarded rule `metric-figure`, so no block of the slide reads smaller than without it. `paginate` ends a page at the last sentence end that fits, wherever it falls, and moves a sentence that does not fit beside what the page holds whole to the next page when a page can hold it alone, so a continuation page no longer opens with a fragment such as "twenty."; a list marker ("2. ") is not a sentence end, and a sentence no page can hold is still split inside. A value's line height stays 1.22 (see the pull request).
