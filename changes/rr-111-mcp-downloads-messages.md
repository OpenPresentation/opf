RR-111: viewer downloads and messages follow Claude's MCP Apps rules. A download's file name is the URI's last segment as written (no percent-encoding, which a host does not decode; the characters a host would replace are replaced in the view), one request runs at a time, the timeout is ten minutes, and the outcomes read "Download started.", "The download didn't finish." and "The download couldn't be confirmed."; a host without downloads after all ("method not found") gets "This host does not offer downloads here" and the copy fallback. Send to Claude handles a refused and an unconfirmed message, says a message Claude took waits for the user's approval (in another host, only that it was sent), and stays usable to retry. When a newer viewer of the same deck opens, the older one greys out, clears its sharing state and stops sending context, messages and tool edits; other decks stay independent. The session is the caller's `session` or is derived from the deck's name, and the order key is the server's clock with a random tie-break; nothing is stored or counted.
