RR-96 (output-changing for colors only, no geometry): color scheme variants. `design.variant` and `slides[n].design.variant`: a background slot string (`"dark1"`, the shorthand, as `colorScheme` takes a string) or `{ background: light1 | light2 | dark1 | dark2, accents?: <permutation of accent1 to accent6> }` for an accent order; the resolved value is always the object (`normalizeColorVariant`) map the roles bg1, tx1, bg2 and tx2 and the accent order over the deck's one twelve-slot scheme, as PowerPoint's `clrMap` does, never a second scheme; `tone: dark | light` on picture and gradient backgrounds picks the map for them; a theme-slot `design.background` stays a shorthand for the variant of that slot. `resolveColorRoles(scheme, { variant, tone, background })` maps background, text, textSecondary and surface through the map and returns `variant`, `map` (with `clrMapAttributes()` for the PPTX `clrMap`/`clrMapOvr`), `accents` and `neutrals`; `resolveSlideContext(...).resolved.roles` is the slide's record. Every neutral is derived from the scheme: `roles.border` (now tx1 at 20% over bg1 instead of a fixed slate) and the new gridline, axis line, chart text, outline, neutral trend and code panel, text and comment colors, each as `{ slot, hex, lumMod, lumOff }` so the PPTX can write `schemeClr` with transforms (`applyLuminance`, `readableSchemeColor`, `codeSyntaxPaletteForRoles`; `codeHighlightColors` takes the panel; `chartSeriesPalette` takes the accent order). The validator resolves the same roles. Documented in `docs/design-resolution.md`. The `opf-presets` design reference, the `opf-author` skill, the format card and the image treatments page document `design.variant` and `tone`, and `examples/technical/color-variants.opf.json` shows a deck variant, dark1 and light2 slides, a toned picture and the derived neutrals on a chart and a table (the example corpus is 128 decks). A variant also hides a less specific level's background in design resolution (a deck variant over the theme's dark2 background is drawn in the variant's bg1).
