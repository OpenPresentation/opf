A metric can be drawn as a gauge: `metric.gauge` (`MetricGauge`: `min`, default 0, `max`, one to six `bands` as a chart's `ChartBand`, and a `target`) draws the metric's number on a half-circle arc from `min` at the left to `max` at the right (in a right-to-left deck too), over its bands in the chart bands' colors, with the value arc in the primary color or in the full color of the band it falls in, a target tick, `min` and `max` under the arc's ends in the value's number format, and the metric's text centered under the arc, the value inside the arc's bowl when it fits there. Only a number draws a gauge (`metric-gauge-value` warns otherwise); a value outside the range keeps its real number while its arc stops at the end, a target outside it is not drawn (`metric-gauge-range`); bands written out of order are drawn sorted (`chart-bands-order`); a region too small for an arc 96 reference pixels wide draws a plain metric (composition reports `metric-gauge-dropped`). A gauge works with a metric computed from data. Core lays it out and plans its drawing for every engine (`layoutMetric`'s `gauge`, `MetricLayout.gauge`, `metricGaugeInput`, `metricGaugeDrawing`). The PowerPoint export draws the track, each band and the value as native block arcs on one center, the target as a line and the end labels as text boxes, tagged into the metric's group as marks with part names (a metric now takes any number of generated marks); the metric's record stores it as authored with the evidence of each part, and import restores the gauge while the parts are as exported, else imports the metric without it (`metric-gauge-not-restored`) and the arcs as shapes. The editor's metric inspector has a Gauge section (on fills `min` 0 and a round `max` above the value; the range, the target and the bands). A metric without `gauge` draws and exports as before. New warnings: `metric-gauge-range` and `metric-gauge-value`.
