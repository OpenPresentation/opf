The OPF viewer names the host it runs in: a host that identifies itself as ChatGPT (its `hostInfo` name or title contains "chatgpt" or "openai", in any case) reads "Send to ChatGPT", "ChatGPT has your edits" and "Sent to ChatGPT", as Claude already did; any other host stays "the assistant". On a phone, Send is compact in the name's row (an icon and "Send"; the whole sentence is its accessible name and title) and the deck's name keeps at least 96px. The More menu ends with what the host reported (`OPF 0.34.1 · Host: <name> <version>`), also the title of the footer's version.
