Layout harvest, two typographic defaults. LH-11: line breaking never splits a number from its unit or `%` ("26 %", "$4.8 M", "12 km", "3 x", "5 pm"; the digits of one figure stay together) and never starts a line with a closing mark (`. , ; : ! ? ) ]`, a closing quotation mark, their CJK and Arabic forms) or ends one with an opening mark; plain text, rich text, heading balancing and a table column's narrowest width all read the rule (`proseTokens`, `lineMayStartAt`), and a no-break space is measured as wide as a space. The rule reads characters, so it holds for right-to-left and CJK text. Where PowerPoint wraps the text itself (native titles and bodies under `bodyText: 'native'`, table cells) the PPTX export writes a no-break space (U+00A0, `bindNoBreak`) at the same places and import turns it back into the space (`unbindNoBreak`). LH-84: a picture taller than wide (a portrait) cover-cropped into a wider frame (an image block or a picture background) now defaults to focus y 0.3 instead of the center, so heads stay in frame; an authored `focus` always wins, every other crop stays centered, and the preview and the PPTX `a:srcRect` read the same core placement (`fitImage`, `defaultImageFocus`). Output-changing for text with a figure and its unit near a line end and for portrait pictures cropped into a wider frame.
