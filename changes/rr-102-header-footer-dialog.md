RR-102 (output-changing for decks with a footer or a slide number with words around it): an exported deck behaves in PowerPoint's Insert > Header & Footer like a deck built in PowerPoint, and the import reads the dialog's changes back.
    - `slideNumberFields: 'live'` is the default (vetoable; `opf convert --slide-numbers` and `convert({slideNumbers})` follow it): `Page {{slide.number}} of {{deck.slideCount}}` and `{{slide.number}} / {{deck.slideCount}}` are the Slide Number placeholder with a live field and the words as fixed runs, so the dialog shows Slide number checked and PowerPoint renumbers. `'static'` stays for Keynote targets. `{{deck.slideCount}}` is fixed text (PowerPoint has no slide-count field).
    - The slide master's Date, Footer and Slide Number placeholders, which every item the dialog turns on inherits, sit where OPF draws that part when it is added to the deck's footer, on one baseline: a date turned on in a footer whose three zones are full goes after the left zone's text instead of on top of it (in a 4:3 deck too), and a footer and number turned on together line up.
    - A current date is the field of the deck's language that shows its `dateFormat` (the dialog shows that Language), else an English (United States) one, else fixed text; the per-language formats were read from PowerPoint 16.0 (en-US, en-GB, en-AU, en-NZ, en-CA, en-IN, de-DE, fr-FR, es-ES, it-IT, nl-NL, pt-BR, pt-PT, ja-JP, zh-CN, ko-KR; ar-SA, he-IL and hi-IN use other calendars). An en-GB deck's default `M/d/yyyy` date was a `datetime1` field in en-GB, which PowerPoint draws as `dd/MM/yyyy`; it is now an en-US field. Import reads a date field's type in its language. A deck with a current date gives the master and layout date that field.
    - Notes and Handouts: the notes master and every notes page carry the page number and the footer text and date the slides show.
    - Import: when the dialog changes a deck's footer so that no inherited value is left that every slide agrees on (Apply to All of a date, a slide's footer turned on where OPF hid it), the footer most slides share becomes `design.footer` again.
