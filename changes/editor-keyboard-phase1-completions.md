Source editor keyboard parity, phase 1 (JSON completions): the list now follows the schema and the catalogs the way VS Code's JSON service does, and more. Keys come from core's `describeField` (`@openpresentation/opf/schema`): required members first, then the common keys in a curated order (a slide: `title`, `subtitle`, `layout`, `items`, `text`, `notes`, ...), with the promoted region keys of a slide hidden until you type three characters of one; keys already in the object are not offered. Accepting a key writes the whole pair with the caret where the value goes (`"description": "|"`, `"items": [|]`, `"design": {|}`), an object with required members (`organization`) writes them as tab stops that `Tab` walks, a comma is added when a property follows, and a key with a closed set of values (an enum, a boolean, a catalog id) opens the list of its values at once. Values: enum values, booleans and catalog ids (the document's own records first, layouts in the order of their intents, with the description and regions in a documentation panel), `{}` and `[]` templates after a colon, and snippets (`slide`, `slide-text`, `slide-image`, `slide-chart`, `slide-quote`, `slide-metric`, `slide-table`, `slide-code`, `slide-two-column`, `section`, `reference`, `dataset`, `deck`) with tab stops. The list opens on `"`, on a word, on `:` and on the space after it, and on `Ctrl+Space` (`Cmd+I`) at every position that has something to offer: after a colon, inside `{}` and `[]`, and in a blank document; free text and numbers still never open it. `Shift+Tab` and `Shift+Enter` accept like `Tab` and `Enter`, `Left`, `Right` and `Backspace` inside the word keep the list open and filter by the text before the caret, and `Ctrl+Space` with the list open shows or hides the documentation. With several cursors the accepted item goes in at each of them. Hovering a key or a catalog id shows its documentation (`Cmd/Ctrl+K Cmd/Ctrl+I` at the caret). The catalog kind of a field now comes from the schema (`catalogKindAt`), not from a table in the editor, and `@openpresentation/opf-editor/schema` re-exports core's helpers. New: `json-editor` options `hover`, `announce`, `syntaxProblems` and `onFocusProblems`. Cases: `test/source-keyboard-json-browser.mjs` (`J-TRG`, `J-CTRL`, `J-INS`, `J-VAL`, `J-RNK`, `J-DOC`, `J-SNP`, `J-ACC-016` to `021`) and `test/source-language-units.mjs`.
