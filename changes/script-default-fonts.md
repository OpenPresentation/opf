Breaking (0.35, output-changing for decks in 19 languages): the default font of every script is now one that ships with Windows by default and draws the script at about the size of the Latin text beside it. A deck or slide that names no font for its script uses Nirmala UI for Hindi, Marathi, Nepali, Bengali, Chittagonian, Gujarati, Punjabi (Gurmukhi), Kannada, Malayalam, Odia, Tamil and Telugu (it was Mangal, Shonar Bangla, Vrinda, Shruti, Raavi, Tunga, Kartika, Kalinga, Latha and Gautami), Leelawadee UI for Thai and Khmer (Angsana New, DaunPenh), Segoe UI for Hebrew (David), Ebrima for Amharic (Nyala) and Yu Gothic for Japanese (Meiryo). All the earlier fonts are optional Windows features, so a deck opened on a plain Windows showed a substitute, and several are small on their body. Pashto and Punjabi (Shahmukhi) take Times New Roman and Arial, as Arabic does, instead of Arial Black headings, which have no Arabic letters. The language vocabulary and the gallery's language records name the schemes `nirmala-ui`, `yu-gothic`, `times-new-roman-arial` and three new ones, `leelawadee-ui`, `ebrima` and `segoe-ui-regular`. Every earlier default stays a scheme a deck can choose, and nothing preserves the old look for a deck that relied on one. The PPTX names the new font in the theme's slot for the script and in its script entry. OPF bundles none of these fonts: the font policy names the open face that previews each script, with a preview-only size factor measured as the sum of the real font's shaped advances over the open face's (Noto Sans Bengali 1.08, Gujarati 1.13, Gurmukhi 1.08, Kannada 1.17, Malayalam 1.13, Oriya 0.98, Tamil 1.04, Telugu 1.17, Khmer 1.19, Hebrew 1.03 and Ethiopic 1.06 as script replacements; Noto Sans Thai 0.96 on the new Leelawadee UI row; Devanagari keeps 1.07). A script of the Latin slot (Ethiopic) takes its factor from the family its theme entry names. In a read-only PowerPoint check of one slide per language, PowerPoint broke every line at the same word as OPF in all 17 languages that changed font.
