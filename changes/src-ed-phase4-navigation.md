Source editor, keyboard parity phase 4 (go to, peek, references, rename): `F12` (and Cmd/Ctrl+click) goes to where the id under the caret is declared, `Alt+F12` peeks the definition in a widget under the line (`Enter` goes to it, `Escape` closes it and returns to the editor), `Shift+F12` lists the declaration and every use with line numbers and slide numbers (Up, Down, Home, End, `Enter` jumps and selects, `Escape` closes) and `F2` renames in an input at the symbol: the new name is checked as you type (not empty, the schema's pattern for that kind of id, no other id of the same kind), and `Enter` changes the declaration and every use in one undoable edit, keeping the caret on the symbol. Works in JSON, YAML and Markdown, also on broken text, for assets (`asset:logo`, Markdown images), variables (`var:brand`, `{{name}}` and `{{name|format}}`), datasets and their columns, references and `cite`, slide ids, beats and regions, and every catalog id (layout, theme, color scheme, font scheme, narrative, audience, purpose, tone): a record the document embeds is jumped to, a record only the registered catalogs have opens a read-only card in the widget (name, description, regions, "Provided by app", and the host's `resolvePreview(kind, id)` when given). Ids of the document and of its embedded catalog records can be renamed; a record of the app, a built-in variable or a read-only editor answers why it cannot. Every command announces what it did, the widgets are named for assistive technology and use only the `--opf-ui-*` tokens, and on a 1000-slide deck each command answers well under 100 ms.
