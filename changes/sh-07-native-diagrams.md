SH-07: native Mermaid diagrams in PowerPoint. `toPptx(deck, { diagrams: "shapes" })`, `convert(..., { diagrams: "shapes" })` and `opf convert --diagrams shapes` write a diagram as one group of native PowerPoint shapes, text and connectors built from the preview's own drawing (pele's laid-out geometry, never a second layout): presets where a node's outline is exactly one, freeforms otherwise, labels as real text at the preview's baselines (a node's label is the node's own text), straight edges without arrowheads as connectors glued to the node sites, every other edge as its exact path with its arrowheads, and the alt text as the group's description. An unchanged group imports back as the diagram (`OPF_DIAGRAM_V1`); an edited one imports as its shapes. Only the families in core's new `DIAGRAM_SHAPE_FAMILIES` (all 32 built-in families, each compared with the preview in PowerPoint 365) are written so; any other diagram, and a drawing with a clip path, filter, pattern, image or right-to-left text, stays the picture with the info finding `pptx/diagram-shapes-unavailable`. The default (`"picture"`) is unchanged. Core: `paintDiagram` takes `{ classes: true }` to keep pele's classes, and `ensureShapes(input, { diagrams: true })` loads the preset geometry for a deck with diagrams.
