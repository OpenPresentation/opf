Hosts get one copy of CodeMirror and a source worker that loads from npm. The `@codemirror/*` and `@lezer/*` dependencies are caret ranges instead of exact versions, so a package manager shares them with an app that uses CodeMirror itself. Two copies of `@codemirror/view` silently broke the source pane's tooltips, completions, problems and find on openpresentation.org and pptx.dev. When the code editor mounts on two copies, it now says so once per page, through `onError` (code `duplicate-codemirror`) or the console. The source worker's entry and the stylesheet are listed in `sideEffects`. With `"sideEffects": false`, a host file that only imported `@openpresentation/opf-editor/source-worker` was emptied by every bundler, and the pane waited 15 s for a worker that never answered. The worker now says it is ready when it starts, and one that does not within 5 s is given up for the main thread. `worker` also takes the URL of a worker script the host built, and the failure messages name the worker (with the fix under the Vite dev server). `docs/embedding.md` ("The source worker") gives the snippet for Next.js (Turbopack and webpack), Vite and esbuild, measured in each.
