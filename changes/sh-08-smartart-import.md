SH-08: SmartArt that PowerPoint users made imports into OPF with its text. Import reads the data model's outline (the entries in order, nested entries, an organization chart's assistants, a name-and-title box as the entry's description, run formatting, line breaks), and the layout decides the form: the pyramid, matrix, cycle and chevron families and Basic Process and Vertical Process become a list on the `pyramid`, `matrix`, `cycle`, `chevrons`, `flow` or `vertical-flow` layout, the list and process families a list on `list` or `process`, hierarchies and organization charts a Mermaid flowchart (assistants dotted, a connection's text as the edge label), and every other layout (Venn, radial, target...) its drawing as overlay shapes through the shape importer, the outline as the first shape's alt text. Nested entries keep their `level` (they were dropped before, with `smartart-flattened`, which is removed). What a form does not keep is reported: `smartart-text-dropped`, `smartart-picture-dropped`, `smartart-formatting-dropped`; `smartart-adapted` (info) names the form chosen. A SmartArt that imported as an unknown "PowerPoint object" before now imports as content.
