Validation explains a slide key that is almost a region key (`bottom+middle:start+center+end`, `top+bottom:start`, `start:top`): it names the key meant, in reading order with rows before the colon, and offers it as a rename. A region written as a bare string, number or list (`"top:start": "text"`) is one finding that shows the `{ "text": ... }` form and offers the fix, instead of two raw "must NOT be valid" and "must be object" errors.
