LH-166: the editor edits icons. `@openpresentation/opf-editor/icon-options` sets, changes and removes the `icon` of a list entry, a metric and a group, each as one undoable patch: `setIcon(editor, path, "lucide:truck")`, `removeIcon(editor, path)` and `setSvgIcon(editor, path, svg, { name })`, with `prepare...` forms that return the patches without a session; `path` may be a selection (`iconTargetForSelection`, `readIcon`). A bare entry or metric becomes `{ text, icon }` or `{ value, icon }`. A pasted SVG goes into the deck's `icons` map under a name (the same SVG is reused, a taken name is refused unless `replace`) and the target references that name in the same patch list, so one undo takes both back; removing the last use of a deck icon removes it from `icons` too. A set icon the validator does not know and an SVG that cannot be an icon are refused with the `opf/icon-unknown` or `opf/icon-invalid` finding's own message (error codes `icon-unknown`, `icon-invalid`, `details.ruleId`), and nothing changes. The editor bundles no icon set: `listIconSets`, `loadIconSets` and `searchIcons(editor, "truck", { set, limit })` read the sets a host registered as a catalog's `iconSets` (`galleryIconSets` of `@openpresentation/gallery/icon-sets`), by name and the source package's keywords, with the ranking of the MCP's `search_icons`. `@openpresentation/opf-editor/icon-picker` (`createIconPicker`) is the DOM control, mounted by `createDesignControls` in its selection section, so the playground, the workspace and the Studio all have it: the current icon, "Choose icon…" with search and a set filter, the deck's own icons, "Paste an SVG" with an optional name (a refusal shows under the box), Remove. The playground registers `galleryIconSets` and bundles Lucide and Tabler (about 2.4 MB more in `playground.js`). `mergeCatalogs` now keeps a later catalog that registers `iconSets` even when its source repeats an earlier catalog's (`galleryIconSets` shares the gallery's source), so `[gallery, galleryIconSets]` reaches the session. See the editor README and docs/icons.md.
