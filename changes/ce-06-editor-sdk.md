CE-06: an embeddable editor. `createOpfEditor(element, options)` (`@openpresentation/opf-editor/workspace`) mounts the source pane, the canvas, the slide navigator and thumbnails, Present, Export, the slide sorter and outline, Layout Studio, the Review and Design panels, Find and autosave over one session and one fonts handle, and returns a handle (`getDocument`, `setDocument`, `session`, `focus`, `setView`, `setSlide`, `present`, `undo`, `on`/`off`, `destroy`). Each part is optional (`panels`), the layout is built (`"full"`, `"canvas"`, `"source"`) or the host's own (`slots`), and the options cover the document or session, catalogs, fonts (a handle, a promise, a function or a lease released on destroy), `imageResolver`, `onAddAsset`, persistence, the source pane's worker, `readOnly`, the first view and panels, density, the theme and the callbacks `onChange`, `onSelection` and `onError`. It is the playground's glue promoted, so `examples/playground.js` is a thin user of it. `@openpresentation/opf-editor/react` adds `<OpfEditor>` and the hooks `useOpfEditor`, `useOpfDocument` and `useOpfSelection` for React 18 and 19 (StrictMode-safe, an empty container on the server, React an optional peer). The editor chrome is themable: `docs/theming.md` is the `--opf-ui-*` token contract (surface, text, accent, border, radius and font, light and dark), `theme: { colorScheme, tokens, dark }` sets them for one editor (also forcing a scheme inside a page of the other), and `[data-theme="light"]` now forces light inside a dark page.
