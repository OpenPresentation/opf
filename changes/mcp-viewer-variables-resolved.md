The OPF viewer draws built-in variables resolved, in the preview and in the thumbnails: a footer `{{organization.name}}` shows the organization's name, as the renderer and the exports already drew it. The viewer printed the token as written (the editor's default view). A press on text that holds a token edits the authored value in the editor's form or in the source; a template still draws its variables as written.
