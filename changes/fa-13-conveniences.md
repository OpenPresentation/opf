FA-13: six small conveniences. `code.highlight` lists 1-based source lines and inclusive `[start, end]` ranges to emphasize (new on `@openpresentation/opf/composition`: `codeHighlightLines`, `codeLineNumbers`, `codeHighlightBands`, `codeHighlightColors`; `validate` warnings `opf/code-highlight-out-of-range` and `opf/code-highlight-range-reversed`, category `content`; pagination keeps each page's lines). `Watermark` takes `text` instead of `src` (exactly one; `layoutWatermark`, on `@openpresentation/opf/composition`, gives the shared geometry: centered, rotated 30 degrees counterclockwise). `TextRun.code` marks an inline code span in the design's code font (`RichTextOptions.codeFontFamily`, `TableLayoutOptions.codeFontFamily`), and Markdown backticks now read and write it (an unmatched or escaped backtick stays text; backticks in plain fields such as titles stay literal). `TextRun.lang` is a BCP-47 tag for one run (it reaches the fragment as `style.lang`; Markdown `{lang=fr-FR}`). `DimensionPreset` gains `1:1` (7.5 x 7.5 in), `4:5` (7.5 x 9.375 in) and `9:16` (7.5 x 13.333 in). Docs: items versus bullets in content-payloads.md. Existing decks that use none of these are unchanged.
