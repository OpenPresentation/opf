Source editor keyboard parity, phase 0 (paste and Format): pasting multi-line text whose last line is a lone `}` or `]` inserted nothing and logged `JSON source and code-editor document must agree.` (the paste ran `indentOnInput`, which re-indented the pasted line, so the text no longer matched the source the edit declared); a paste, and every `api.replace`, now runs as `input.paste` or `input.replace` and is inserted as written, as in VS Code. Format document works in every format and is one undo step with the cursor kept on its token: `Shift+Alt+F` (VS Code's key) and `Cmd/Ctrl+Shift+F` and the Format button do the same in JSON (also while the text does not parse; before, it did nothing without a word), YAML (new `src/source-format.js`: the `yaml` library's document round trip, so comments, blank lines, quote styles, number spellings and key order stay; the button used to rewrite the text from the document and drop the comments) and Markdown (at most one blank line between blocks, code fences untouched, front matter formatted as YAML, one newline at the end). A format that would change the document, or YAML with errors, is refused with a message in the status line. New dependency: `yaml` (already a dependency of core). `JsonEditorApi` gains `replaceDiff(text)`, `indentUnit()` and the `keepSelection` and `userEvent` options of `replace`; `JsonCodeEditorOptions` gains `onFormat`. Cases: `J-PST`, `J-FMT`, `Y-FMT`, `M-FMT`, `test/source-format.mjs`.
