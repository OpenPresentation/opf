SH-05: PPTX import of shapes. `fromPptx` reads native shapes (`p:sp`, `p:cxnSp`) as OPF shapes. A deck the export wrote returns its shape blocks, overlay shapes and connectors as authored: the native name says which (`OPF shape slides.N.blocks.I.shape`, `OPF shape slides.N.shapes.I`, `OPF connector slides.N.shapes.I`), every shape property is read back from the DrawingML (the preset and its `a:avLst` through `adjustFromDrawingML`, `a:custGeom` as `path`, fill, opacity, `stroke`, `style` from `p:style`, the effects from `a:effectLst` with the shadow presets by name, rotation, flips, text, anchor, insets, direction, alt text, decorative, hidden and the click link; `a:lumMod` and `a:lumOff` as `{ color, lighten }` and `{ color, darken }`), and the slide's stored record (`OPF_SLIDE_V1`, new field `overlays`) returns an overlay entry's `id` and `at` anchor and which connector sites were named, while the slide is as it was exported. A deck PowerPoint wrote has its free-positioned shapes that draw something imported as overlay shapes placed by fractions of the slide, its `p:cxnSp` connectors as connectors bound by id from `a:stCxn` and `a:endCxn` (a free end is a line shape), and the shapes in groups flattened with the group's scale, flips and rotation applied; a text box and a rectangle that draws nothing keep today's text import, a filled shape across the whole slide is not imported (`shape-not-imported`), and an opaque shape PowerPoint drew behind a text box, picture, table or chart is reported (`shape-covers-content`) because an overlay is drawn over the content. 3-D, preset shadows, fill overlay, wrap, columns and autofit, alternative text titles, hover links, locks, black-and-white mode and custom data are dropped and reported as `shape-property-dropped` (`import/shape-property-dropped` in an `opf convert` report) with the `property` named. The content record now stores a shape block's box (it stored none), so a shape block returns to its place. A non-text PowerPoint shape no longer imports as a "PowerPoint shape: name" text block: it is an overlay shape. `docs/shapes.md` has the import section and the opf-export skill the summary.
