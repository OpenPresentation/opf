FA-31 (breaking): header and footer values use the `{{ }}` variables. `HeaderFooterItem` loses `organization`, `speaker`, `section`, `slideNumber` and `slideNumberFormat` with no alias (a deck that uses one is invalid; `HeaderFooterItem` now rejects unknown keys), and the `{current}`/`{total}` syntax goes with them: write the values in the zone's `text` in the order you want (`"{{organization.name}}"`, `"{{speaker.name}}, {{speaker.title}}"`, `"{{slide.section}}"`, `"{{slide.number}} / {{deck.slideCount}}"`, a line break as `\n`). New slide-scoped built-ins `{{slide.number}}` (the displayed number after pagination), `{{slide.section}}` (the slide's `section`) and `{{deck.slideCount}}` (the slide count after pagination) work in any string, body text included; `slide.` is a reserved prefix. `resolveVariables` leaves them as written (an escaped `\{{slide.number}}` stays escaped); the new `resolveSlideVariables(slide, { slideNumber, slideCount })` substitutes them in a slide, and `resolveSlideContext` returns that substituted slide as `context.slide`, so engines compose and draw `composeSlide(context.slide, context.options)`. `layoutFurniture` substitutes them in header and footer `text`, and every `{{slide.number}}` adds a `slideNumber` entry to `FurnitureTextPart.fields`; `FurniturePartBase.field` narrows to `text | image | logo | socials | date`, and `formatSlideNumber` and `DEFAULT_SLIDE_NUMBER_FORMAT` are removed. `paginate` measures with the substituted values and returns slides with the tokens kept, and runs its slide-count fixed point whenever `{{deck.slideCount}}` appears in the deck. Validation reports an unknown `slide.*` name, `var:slide.*` and `var:deck.slideCount` as `variable-unknown-builtin`, and warns `variable-builtin-missing` at each slide without a `section` that uses `{{slide.section}}`, directly or through the header or footer it inherits. `listBuiltinVariables` lists the three with `scope: "slide"`; every entry now carries `scope`. The example decks are migrated. Fields in one zone now stack logo, image, text, socials, date, so a migrated zone that combined a slide number with socials draws the number above the socials.
