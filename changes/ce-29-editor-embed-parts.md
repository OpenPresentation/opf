CE-29: more of the editor for embeds. Toolbar items `design` (a quick menu for the deck's theme, color scheme and font scheme and the slide's layout, a popover or a bottom sheet on a phone; `createDesignMenu` from `/design-menu`), `review` (a status pill, "Valid" or "N issues", that opens the Review panel; without one it runs the checks headless and emits `review-open`; `createReviewPill` from `/review-pill`), `help` (a searchable keyboard-shortcuts sheet built from the bindings the editor really has, also on `?`; `createHelpButton` from `/shortcuts-sheet`, handle `shortcuts()`) and `actions` (the host's own buttons: option `actions: [{ id, label, icon, run, enabled, pressed, primary }]`, handle `setActions()`; `createToolbarActions` from `/toolbar-actions`). Slide management on the thumbnail strip (`slideActions`, on by default in `full` and `embed`): an "Add slide" button with a layout menu and a context menu (right-click, Shift+F10) to duplicate, delete, hide and move slides, plus Alt+Arrow and Delete on a focused thumbnail. Unsaved changes: `dirty` (the document, or a source draft that is not yet a valid deck, differs from what was last saved or loaded), event `dirty`, `markSaved()`, `save()`, Ctrl/Cmd+S emits `save` with the document and its text, and `guardUnload` warns before the page closes; React `useOpfDirty`, Svelte `opfDirty`. Styling hooks: bar and title tokens (`--opf-ui-bar-*`, `--opf-ui-title-*`, `--opf-ui-z-overlay`), an `icons` option for every part that draws one (`resolveIcon` from `/icons`), `styles.layered.css` (the same CSS in `@layer opf`, so a page's own rules win), and `docs/styling.md`, the classes and attributes each part keeps stable.
