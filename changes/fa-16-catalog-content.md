FA-16 (breaking, pre-v1): catalog content gaps. The 30 bundled layout records that carried only placeholders (`blank`, `title`, `title-subtitle`, `text-1x` to `text-3x`, `list-1x` to `list-6x`, `number-1x` to `number-6x`, `chart-1x` to `chart-3x`, `code-1x`, `image-1x` to `image-3x`, `image-bleed`, `media-1x`, `quote-1x`, `table-1x`, `timeline-1x`) now have a `summary`, a `description` and `tags`. The chart, list and number layouts carry the `design` values (`contentAlignment`, `contentBox`, `contentDirection`, `listBullet`) the gallery layout data already held; the others carry none, because nothing in the gallery data states one. Every bundled layout record's `preview.vectorSrc` points at its published SVG (`https://www.pptx.gallery/layout-previews/<id>.svg`). Font-scheme `languages` holds languages catalog ids (`thai`, `hindi`, `chinese-simplified`) instead of human names: `font-scheme.schema.json` adds the id pattern, all 60 records that list languages are migrated, `resolveScriptFonts` matches a scheme's list against the language record's id (a name no longer matches), and `check:spec` rule (j) requires every entry to be a bundled language id. `Sanskrit` (Mangal) had no languages record and is dropped; Raavi's `Punjabi` becomes `punjabi-gurmukhi`. The social-platform schema drops `icon`, `iconLight` and `iconDark` (no record sets them and the gallery serves no platform icons). `sync-gallery-catalog.mjs --rehash --match-gallery` also sets the gallery block of a mirrored kind, for a core-first edit that the gallery PR publishes identically.
