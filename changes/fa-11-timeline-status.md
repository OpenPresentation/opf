FA-11: `TimelineEvent.status` (`done`, `current` or `planned`) marks an event's progress. Both engines draw it from the deck's colors: `done` is a filled marker with normal text, `current` ("we are here") is a ringed marker with a bold label, and `planned` is a hollow outlined marker with muted text kept at 4.5:1 or more. An event without a status draws and exports exactly as before. Core's `layoutTimeline` puts `status`, `ring` and `strokeWidth` on each marker and `status` on each event's text parts, and the new `timelineMarkerShapes` and `timelineTextColor` (with `TIMELINE_STATUSES`, `TIMELINE_TEXT_MIN_CONTRAST`, `TIMELINE_OUTLINE_MIN_CONTRAST` and the `TimelineStatus`, `TimelineMarkerShape` and `TimelineStatusColors` types) derive the shapes and colors both engines draw. Markdown writes status as a task-list prefix on the event line (`[x]` done, `[>]` current, `[ ]` planned), conversions that cannot show it (list, text, table) report it as lost, and the text-contrast audit samples a planned event's muted text color. Schedule health (at risk, blocked) is deliberately not a status.
