FA-01 (breaking, pre-v1, no aliases): layout records use the deck's design vocabulary and one content-kind vocabulary. `placeholders[].type` is exactly `title subtitle tag text list image video chart table code metric quote timeline` (`picture` and `diagram` become `image`, `media` becomes `video`). A layout's `design` object (`DesignHints`: `titleAlignment`, `contentAlignment`, `contentBox`, `contentDirection`, `chartPrimary`, `imageFill`, `listBullet`, `slideImage.position`; lowercase values, no `None`) replaces `contentAlignment`, `contentBox`, `contentTypeChartPrimary`, `contentTypeImageFill`, `contentTypeListBullet`, `slideTitleAlignment`, `slideImageAlignment` and `slideLayoutDirection`. `contentType`, `contentMultiple`, `contentTypeListHeading`, `slideTag`, `slideTitle`, `slideSubtitle` and the boolean `slideImage` are removed: `layoutContent(record)` derives `{ kind, count, heading }` from the placeholders. All 100 bundled layout records are migrated; composition reads `design.contentDirection`, `design.chartPrimary` and `design.slideImage` from the layout record with the same precedence as before. `check:spec` verifies that `DesignHints` and the deck's `Design` agree. New exports (from the `./composition` entry): `layoutContent`, `LAYOUT_BODY_KINDS`, `LayoutContent`, `LayoutBodyKind`.
