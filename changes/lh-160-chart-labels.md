LH-160, LH-161 (output-changing for charts): a histogram or Pareto chart of a lone value column draws only as many bins as its plot can label one beside another (core `chartHistogram`, `layer.histogram`; Scott's count when there is room, written as `cx:binCount`), its bin edges are rounded to the decimals the bin width needs and written as the category axis number format so PowerPoint keeps each label on one line, and per-bar data labels that would overlap are dropped in the preview, the native part and the classic fallback; the histogram bin helpers `scottBinCount` and `histogramBins` (new `count` and `decimals` options) are core's, the renderer and the exporter re-export them. A pie's or doughnut's last slice is moved off the first when they would read as one tone (`chartSlicePalette`: that one slice along the lightness axis to 11 L* from the first and from its neighbor, every other slice keeps the palette color), so `opf/chart-color-only` reports no wrap pair on the gallery color schemes; the rule now holds only a pie or doughnut to the wrap pair (a treemap or funnel has no circle). Pies whose last slice is a scheme color close to the first draw that slice in a different lightness (about half of the pies of 3 to 12 slices on the gallery schemes change none; the PPTX export writes the moved slice as an sRGB literal). Gallery records are unchanged, so no `drawing` entry.
