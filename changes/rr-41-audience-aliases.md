RR-41 (catalog data, additive; no schema or API change): the six plural audience ids are deprecated aliases of the singular ids pptx.gallery publishes, as FF-37 planned: `executives` to `executive`, `investors` to `investor`, `customers` to `customer`, `sales-team` to `sales`, `marketing-team` to `marketing`, `regulators` to `regulatory`. Each record keeps resolving unchanged and gains `deprecation: { replacedBy, reason }`; its index entry gains `deprecated` and `replacedBy`. `validatePresentation` warns (`deprecated audiences catalog id 'executives'; use 'executive'`), never errors, and `lintPresentation` reports `opf/deprecated-catalog-id`. The 81 bundled examples (111 references) and `spec/reference/engine-defaults.json` moved to the singular ids; schema and doc examples follow. The change starts in core (core is the source of truth since the FF-37 decision) and the new `node scripts/sync-gallery-catalog.mjs --rehash` rewrites the audiences index and manifest hashes; pptx.gallery adopts it with the next `@openpresentation/opf` release. No example geometry or composition changes (the audience is not drawn); an exported PPTX of the 81 examples records the singular id in its document-provenance metadata.
