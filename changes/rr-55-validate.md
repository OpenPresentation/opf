RR-55 (breaking, no deprecation; core 0.14.0 and CLI): one checker. `validate(input, options?)` replaces `validatePresentation`, `lintSource`, `lintPresentation`, `auditSource` and `auditPresentation`, and `assertValid(presentation)` (an assertion that narrows to `Presentation`, throwing `OPFValidationError` with the `report`) replaces `assertValidPresentation`; the generic `validate(value, kind)` is internal, `validateCatalogRecord` stays and returns a report. The input is a parsed presentation or strict JSON text (line and column, duplicate keys; YAML and Markdown are never sniffed). The report is `{ valid, findings, counts, schemaValid, checks }` with `Finding`, `FindingReport` and `ValidationReport` types and the published `spec/schemas/finding.schema.json` (RFC 6902 `fixes`); findings have a stable `opf/<rule>` id, a severity and one of six categories (`format`, `references`, `policy`, `accessibility`, `layout`, `content`). `valid` means no error finding, and only `format`, `references`, `policy` and an unfilled variable in a deck that is not a template can be errors by default; a missing `asset:` reference now makes a deck invalid. `only`, `ignore` (rule ids or categories), `severity`, `ignorePaths`, `catalogs`, `contracts`, `thresholds`, `fonts` (`textMeasurement`), `template` and `values` are the options; composition is lazy, so `{ only: ['format'] }` builds no layout and costs what `validatePresentation` cost. Rules: the 21 objective accessibility, layout and content rules stay (ids `audit/<x>` become `opf/<x>`); `font-family-count`, `slide-word-count`, `title-position` and `small-cell` and their thresholds are deleted; `unfilled-variable` and `variable-unfilled` merge into `opf/variable-unfilled`; an authored `overflow: "error"` is a warning; `validationRules`, `findValidationRule` and `DEFAULT_VALIDATION_THRESHOLDS` replace the audit equivalents. The `./lint` and `./audit` subpaths are removed. CLI: `opf validate` is the only checker (`--only`, `--ignore`, `--fail-on <error|warning|info>`, `--format json|text`, `--list-rules`, `--config`); `opf lint` and `opf audit` are removed; `--strict` is replaced by `--fail-on` on every command; write, render, export and import commands check `format` and `references` and report `findings`; invalid JSON is an invalid document (exit 1). Markdown results carry `findings` (`Finding & { location }`) and take `validate?: boolean | ValidateOptions`. Guide: [docs/validate.md](docs/validate.md); migration: [docs/migrations/0.14.0.md](docs/migrations/0.14.0.md).
