FA-20 (breaking, OPF 0.15): catalogs group the records a document embeds by the catalog they came from. `catalogs` is `{ default?: Group | false, custom?: Group, <name>: Group }`; a group is `{ source?, layouts?, themes?, colorSchemes?, fontSchemes?, narratives?, audiences?, purposes?, tones? }` with records keyed by id and no `$schema` or `id`. Every content reference (`Slide.layout`, `design.theme`, `design.colorScheme`, `design.fontScheme`, `narrative`, `audience`, `purpose`, `tone`, a theme's schemes) is a bare id or `name:id`; URL and `pkg:` references, `catalogs.<kind>.records` and `catalogs.<kind>.source` are gone, `design.theme` is a reference string only, and a reference inside an embedded record resolves in its own group first. One resolution rule for every kind (custom, default's embedded records, the catalog the host registered for its source); a reference that resolves nowhere is the warning `opf/unresolved-reference` (replacing `opf/catalog-reference`, `opf/catalog-source` and `opf/deprecated-catalog-id`, and the `unresolved-layout`, `unresolved-theme`, `unresolved-color-scheme` and `unresolved-font-scheme` diagnostics), an undeclared prefix is the error `opf/undeclared-catalog`, and a record embedded under `default` or a named group that the catalog registered for its source does not publish is the warning `opf/catalog-record-not-in-source`. Hosts register catalogs with one option on every entry point, `catalogs: Catalog[]` (`{ source, <kind>: { <id>: record } }`, the first is the host default), including `paginate`, `stats` and `resolveScriptFonts`; `strictReferences` makes `resolveSlideContext` and `paginate` throw `OPFUnresolvedReferenceError`. New helpers `embed` (replacing `bundle`), `copySlides` and `updateFromCatalog`, plus `resolveReference`, `parseReference`, `catalogRecords` and `resolveDesignRecords`. `chart.type`, the `language` tag (BCP-47 only; catalog ids such as `english-us` are invalid) and `socials` keys are engine vocabularies validated by the schema (`CHART_TYPES`, `LANGUAGES`, `SOCIAL_PLATFORMS`); a font scheme's `languages` list holds BCP-47 tags. Record schemas lose `deprecation`. The CLI command `opf bundle` is `opf embed`, `opf catalog` lists records keyed by id and drops `--all`, and a validate configuration's `catalogs` is an array of catalogs.
