SH-06: shapes in the editor and the MCP. The editor inserts, restyles and adjusts shape blocks, each edit one undoable change: a shape picker (`@openpresentation/opf-editor/shape-picker`: `createShapePicker`, `createShapeMenu`; the playground's **Insert shape**, **Add content > Shape** and **Change shape…**) with PowerPoint's nine gallery groups, a tile drawn from each preset's geometry and a search by DrawingML name, Aspose name and common words; the yellow adjust handles on a selected preset shape (drag, arrow keys, Escape; fractions and degrees pinned to each handle's range); and a **Selected shape** section of the design controls (`shape` in `DESIGN_CONTROL_SECTIONS`) for the preset and its adjust values, fill (none, color, gradient, pattern), opacity, line (color or gradient, width, dash, cap, join, miter limit, compound, alignment, arrowheads, sketch), style, the six effects, rotation and flip, text, anchor, padding, direction, alt text, decorative, hidden and link, with Lighter and Darker tints on every color. `@openpresentation/opf-editor/shape-options` is the same from code: `insertShape`, `setShapePreset`, `setShapeAdjust`, `setShapeProperties` (each with a `prepare...` form), `searchShapes`, `shapeGroups`, `readShape`. A shape's outline is selected, not edited as text, when clicked; `createCanvasEditor` takes `shapeTools: false` to leave the handles out. Core gains `@openpresentation/opf/shape-catalog` (`SHAPE_CATEGORIES`, `SHAPE_CATALOG`, `searchShapeCatalog`, `shapeThumbnail`, `shapeThumbnailSvg`): the 187 presets in PowerPoint's gallery groups with their Aspose names and keywords. The MCP has a `search_shapes` tool (query, category, limit): each preset with its DrawingML name, Aspose name, group, default frame, adjust values (default, range, unit, whether a handle moves it) and a small SVG. See docs/shapes.md.
