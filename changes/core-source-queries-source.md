`@openpresentation/opf/source` (new, browser-safe subpath): text addressing and JSON syntax recovery for source editors. `locate(text, "json", pointer, { part })` returns the range (`{ offset, length, line, column }`, the `Finding.location` convention) of a JSON Pointer or segment array: its `value`, `key`, `entry` (key through the end of the value), `open` (the first character, where a "missing property" finding points) or `colon` (key through the colon); a missing node returns the nearest ancestor with `exact: false`, and it reads text with syntax errors, comments and trailing commas. `pathAt(text, "json", offset)` returns the document path under a caret and whether it is on a key, on a value or between members. `analyzeJsonSyntax(text, { limit })` is the root-cause analyzer: one problem per cause in position order (at most five), with a range, a plain-language message, a hint (`next`) and the fixes that repair it (`Insert comma`, `Remove comma`, `Add { }` or the value the schema suggests, `Remove "design"`, `Insert }`, `Use double quotes`, `Replace with straight quotes`, `Quote the value`, `Quote the property name`, `Remove comment`, `Wrap in { "slides" ... }`, `Insert minimal deck`, `Switch format to YAML`), for a key with no value, a missing or trailing comma, a missing colon, an unclosed object, list, string or comment, single and typographic quotes, bare words (`True`, `None`, `NaN`), unquoted names, bad numbers and escapes, text after the root, a top level that is not an object, and YAML or Markdown pasted in. YAML and Markdown addressing is not there yet: `locate` and `pathAt` return `undefined` for them.
