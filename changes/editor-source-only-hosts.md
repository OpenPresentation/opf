A host that mounts only the source pane through the editor SDK loads only what the pane needs. `createOpfEditor(el, { layout: "source" })` now builds the source pane alone, with no empty slide stage or status column, and the pane fills the element. The `/workspace` entry no longer imports the renderer or the slide parts up front: the canvas, the slide row, the presenter, Export, Review, Find, Design, the sorter, the outline and Layout Studio are one chunk, imported on demand by any layout that shows them. Measured with esbuild (ESM, code splitting, minified), a source-only host loads 1,914 KiB up front (602 KiB gzip) instead of 3,086 KiB (1,007 KiB gzip), and `test/workspace-bundle.mjs` keeps the renderer out. A layout with slides now mounts its parts after that chunk has loaded, so await `ready` before you use them. `layoutOptionsFor` plans scripts with the fonts handle's own `textMeasurement.forScripts`. The new `editor.setSourceText(text, { format, name })` and `sourcePane.setSourceText(...)` load raw text into the pane without converting it: a file as it was read, or a draft that does not parse. This replaces calls to `sourcePane.editor.api.replace`. The exact-source JSON writer is the public entry `@openpresentation/opf-editor/exact-source` (`updateJsonSource`, `createSourceMemory`, `findDuplicateKey`), so hosts that keep authored JSON can drop their own token parser.
