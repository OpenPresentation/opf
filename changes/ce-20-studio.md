CE-20: the Presentation and Slide Studio, `createOpfEditor(el, { layout: "studio" })`, a Figma Auto Layout-style editor for OPF decks over the same session, canvas, source pane, presenter, Review and export: a filmstrip over a layers tree, the rendered slide in a zoomable viewport (zoom steps, fit, fit width, pinch, Space and the hand tool) with an overlay of hover, selection, container outline, label chips, findings badges, track dividers, drop lines and the ratio badge, and a Design panel bound to the selection (the existing design-control sections, plus the composition of a group, region or slide). Selection is one ordered list of sibling keys (id paths) across the canvas, the layers, the filmstrip, the Design panel and the source split (synchronized both ways through the CE-17 cursor event and `revealPath`); deep select with Enter and Esc, Shift+click sibling multi-select, drag to reorder or move into a group or region with drop lines and reasons for a refused drop, group and ungroup, duplicate, delete, track resize, copy, cut and paste of blocks and slides (across editors, with catalog records namespaced), Insert by block kind (also by dragging onto the slide), + Slide by layout, double-click or typing to edit text, Present, a context menu, a shortcut sheet (`?`) and a Figma-parity keymap from one command registry (`editor.commands`), touch (long-press menu, hold-to-drag, a floating action bar, a bottom sheet on phones) and one undo history shared with the source pane: every command is one validated change. The `playground` preset arranges the same editor for first contact and `editor.setLayout("studio" | "playground")` switches in place, keeping the document, history, slide and selection. "Edit layout" forks a gallery layout into the deck as `<id>-custom` and opens it in Layout Studio with a breadcrumb back. New handle members: `layout`, `setLayout`, `selection` (a list in the Studio), `select(keysOrPaths)`, `zoom`, `setZoom`, `fit`, `openLayout`, `commands`; new events `zoom`, `layout`, `command` and `layoutStudio`. React: `hostPanels` with `render` (portals into the Studio's panels) and `useOpfCommands(editor)`. The canvas gains `targets: "passive"`, `escape: "commit"`, `setTextEntry` and `beginEdit(path, { point })`; three theme tokens (`selection`, `hover`, `canvasBackground`); the first resize of a content-sized column now starts from the drawn heights instead of jumping. Docs: `packages/editor/docs/studio.md`; try it with the editor's `studio.html` page.

    Also: the source pane's format button is named with its visible extension ("Source format .opf.json", WCAG 2.5.3), its line numbers use the muted text color (4.5:1), and the code text is focusable for its scrolling region (axe); the editor's font gate remembers that a frozen document needs no more faces, the canvas, the workspace and the slide manager read the session's frozen snapshot instead of copying the deck on every read, and the thumbnail cache's `peek` reads a cached slide without drawing it.
