A lone list whose entries pair a label with a description and carry icons keeps its icons (output-changing for such slides): the list's growth to its display size measured it with its chip column, which took a line from the descriptions, so the list did not grow while the same list without icons did, and the size guard then dropped every chip with `opf/icon-dropped` on a slide with room for them. The chips are now drawing in that measurement, as a badge list's badges are: the list grows as it would without them, as long as it still fits with them, and draws its chips (or, when every entry has an icon and the cards read as large, as icon cards). The slide's `composition.mode` now chooses between the two drawings of such a list (output-changing only for slides that set a mode): where the arrangement composition resolves for the list is a column (`composition.mode: "column"`; in a layout, the slide's own mode where it arranges the list's region), the list stays ruled rows with each entry's chip at the start of its row (the end in a right-to-left deck), at the size the rows have without icons; a row, a grid or no direction draws the icon cards as before. No text is set smaller; no slide of the examples corpus or of the gallery's layout preview decks moves.
