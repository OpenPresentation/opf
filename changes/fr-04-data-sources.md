Breaking (0.37, FR-04; no drawing changes): a dataset and inline chart data say where they came from in their own keys, and a new root `datasources` map describes each place data lives once. The nested `source` object (`{ src, sheet, range, fields, retrieved, description }`) is removed, with no alias: a 0.36 deck that has one fails validation (`opf/schema` at the `source` key) until `opf fix deck.opf.json -i` rewrites it (the safe fix `use-datasource`). Before: `"source": { "src": "./data/revenue.csv", "sheet": "FY26", "range": "A1:C13", "retrieved": "2026-10-05" }`. After: `"datasource": { "src": "./data/revenue.csv" }, "query": "FY26!A1:C13", "retrieved": "2026-10-05"`. `sheet` and `range` fold into `query` (a sheet name with a space is quoted, `'Q3 plan'!A1:B9`), `description` moves into the inline data source, and `fields` is dropped (the fix says so). New keys on a dataset and on inline `chart.data`: `datasource` (a string is only ever the id of an entry of `datasources`; a file or URL is the inline object `{ "src": "./revenue.csv" }`), `query`, `retrieved` (a date or a date-time), `version`, `sha256` (the hash of the source file's bytes as retrieved, 64 lowercase hex digits) and `generator` (`{ type: "human" | "model", name }`). A data source takes `title`, `description`, `connector`, `src`, `license`, `refreshEvery` (an ISO 8601 duration; no engine acts on it) and `extensions`, and never holds credentials. New rules: `opf/datasource-unknown` (error), `opf/datasource-credentials` (a `src` with a user and password, or a key or token in its query string; warning) and `opf/dataset-stale` (warning, only when a date is passed: `validate(deck, { asOf })`, `opf validate --as-of <date>`; core never reads a clock). Engines never read, fetch or refresh a data source; the keys travel through editing, Markdown, YAML and the PowerPoint document tags (`OPF_DATASOURCES_V1` beside `OPF_DATASETS_V1`) unchanged. In code: `DataSourceRef` is replaced by `DataSource`, `DataGenerator` and `DataProvenance`; `resolveChartData(...).source` is `.provenance`; `stats` reports `withDatasource` and `datasets.items[].datasource` where it reported `withSource` and `source`; the editor's `prepareDatasetImport` takes `provenance` where it took `source`; `opf ingest --dataset` writes `datasource`, `sha256` and (with `--date`) `retrieved`. See `docs/data-sources.md`. Removed from the schema with it: `opf.schema.json:$defs.DataSourceRef`.
