# OPF 0.12.0 migration notes (planned)

## Removal of chart types outside the Aspose.Slides-supported set

The bundled chart-type catalog covers only the chart types Aspose.Slides
officially supports, with one record per Aspose.Slides `ChartType`. See
[the chart-type reference](../programs/font-fidelity-everywhere/aspose-chart-types.md)
for the sources and the full mapping.

The records listed below are deprecated in the release after 0.11.0 and
removed in 0.12.0:

- **Until 0.12.0**, they still resolve and validate. Validation reports a
  warning that names the replacement:
  `deprecated chartTypes catalog id '<id>'; use '<replacement>'`.
- **From 0.12.0**, they become unknown ids. Documents that still reference them
  get an `unknown chartTypes catalog id` warning.

Before upgrading, replace each deprecated id with its replacement. Nothing is
lost:

- Series count and map geography come from `chart.data`, not from the chart
  type.
- The bullet, sparkline, dot-plot, dumbbell, high/low and Pareto compositions
  were never a single PowerPoint chart type.

```diff
- "chart": { "type": "stacked-column-2x", "data": { ... } }
+ "chart": { "type": "stacked-column-3x", "data": { ... } }
```

A document that must keep a removed record can inline it under
`catalogs.chartTypes.records`, or point `catalogs.chartTypes.source` at a
catalog that still defines it.
