## Progress log

- 2026-10-25: program opened; the first host is pptx.dev.
- 2026-10-26: CE-06 in review: `createOpfEditor` (`@openpresentation/opf-editor/workspace`), `<OpfEditor>` and the hooks (`/react`), the `--opf-ui-*` token contract and the `theme` option are in the opf PR, and `examples/playground.js` is a thin user of them. openpresentation.org's playground runs on the SDK in a draft PR (Data-Advantage/openpresentation-site) that waits for the editor release. Done when both are merged and released.
- 2026-10-25: CE-01 done in opf#863: precompiled validators by default under the `workerd`, `worker` and `edge-light` conditions, an explicit `@openpresentation/opf/precompiled` import for other hosts, and a `workerd` lane in the core job. Probes for CE-02: `toSvg` and `toPptx` run in workerd for a one-slide deck (`toPptx` with `nodejs_compat`); their bundles are 4.8 MB and 8.8 MB unminified.
- 2026-10-26: CE-04 and CE-05 landed in opf#862 (`assignIds`, id-addressed paths, `documentHash`, `expectHash`, `touches`, and the editor's id paths); rows updated. CE-06 is done: openpresentation-site#162 merged on 0.27.0, so openpresentation.org's playground runs on the SDK.
- 2026-10-26: CE-17 in review: the source pane tells the host where the caret is (`cursor` event and `getCursor()`, with the pointer, the id path and the selection, in JSON, YAML and Markdown; `onCursor` on the SDK and React, `useOpfCursor`), `revealPath` scrolls a pointer or range into view without taking focus, and `setDecorations` draws the host's own marks and line classes by path or range in named groups, apart from the editor's own. Added from the oss-first study (pptx.dev drops Monaco once this lands, PD-20). Done when merged.
- 2026-10-26: the owner accepted decisions D1 to D5 of the OSS-first study: the Playground becomes a preset of the Studio (D1); slides stay auto-layout, with no free x/y positioning in the Studio or the format (D2); the first host drops its Monaco source editor right after CE-17 (D3); hosts embed the npm package with their panels in slots, not an iframe or a fork (D4); the library browser, value provenance and agent tool definitions are open (D5). CE-18 to CE-27 added.
- 2026-10-26: CE-18 in progress in opf#891: the studio kit in `packages/editor/src/studio-kit/` (internal: no package subpath yet), Layout Studio rewired onto it through `src/layout-adapter.js` with its suites unchanged, and kit-level tests for each part.
- 2026-10-26: CE-19 in progress in opf#895: `src/slide-scene.js` (the pure scene of a slide from its composed geometry: nodes keyed by id path, boxes in slide units, containers with tracks, hit chain, click and drop targets), `src/slide-edits.js` (reorder, move into and out of groups and layout regions, group and ungroup, duplicate, delete, track resize as `composition.weights`, copy and paste of blocks and slides, slide reorder, each a validated prepared patch) and `src/slide-adapter.js` (`createSlideAdapter(session)`, the kit's document adapter: one `applyPatch` per edit guarded by `expectHash`, gestures that preview without writing, selection restored on undo and redo). Internal, no package subpath; unit tests over the examples corpus.
- 2026-10-26: CE-20 in progress in opf#899 (draft): `createOpfEditor(el, { layout: "studio" })` over the session, canvas, source pane, presenter, Review and export, with the `playground` preset and `setLayout`; the Studio modules are `src/studio.js` (shell and controller), `studio-canvas.js`, `studio-layers.js`, `studio-design.js` and `studio-commands.js`, over the CE-18 kit and the CE-19 slide adapter. Acceptance tests 1 to 14 and 17 of STUDIO-SPEC section 12 pass in `test/studio-browser.mjs`; the first resize of a content-sized column no longer jumps. Touch, performance, React `hostPanels` and the harness page follow in the same PR.
