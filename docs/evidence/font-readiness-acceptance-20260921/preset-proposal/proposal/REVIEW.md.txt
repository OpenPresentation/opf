## Intended behavior and guards

- A contiguous preset group holds exact initial/current source, format, actual public EditorSession and public undo/redo depths. React toast state only displays that group; synchronous refs enforce it.
- All ordinary source and format setters invalidate the group before updating state, even for identical bytes. Every non-owned session event also invalidates it, including an identical-document `file-import`, normal canvas edits, Undo/Redo and recovery. Returning to old bytes cannot revive a group. New run, raw import, hydrate, version selection, revert and existing metadata/filename/gallery writers already pass through those setters.
- Both handlers commit a pending inline draft first and reread current source. Undo all verifies that the group survived that commit. A valid newer edit is retained; a rejected draft blocks the action. The transaction path checks semantic session/source equality even with the canvas unmounted, and requires its subscription readiness marker.
- Schema and source representation are preflighted before the session receives one public root patch. This includes all preset catalog changes and JSON duplicate-key rejection for real changes. A semantically identical ordinary preset does not create a toast or history entry.
- A one-shot token identifies the exact synchronous patch callback. Its current session, source/format, semantic before/after and public history depths must match. The callback consumes the token; the caller checks its acknowledgement, rejection counter and resulting raw/semantic document, with unconditional token cleanup in `finally`. No snapshot object-identity contract is used.
- Undo all creates one undoable revert transaction using the bridge's validated raw override. It restores original bytes even when a preset cycle returned to the original semantic value but normalized an escape token. The bridge then supplies exact ordinary Undo/Redo. If bytes already match, the group clears without a new history entry. There is no additional semantic undo stack or repeated-Undo loop.
