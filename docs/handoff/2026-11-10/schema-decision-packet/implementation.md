## Typed native provenance

`legacy-tags.js` is a new implementation, replacing the proposed untyped tree walk. The actual document, slide, data, datasets, image, annotation and furniture readers select their own family. Only declared structural paths, zones, alignment fields and old anchor size keys are adapted. Unknown fields, literal values, extension subtrees, ids and XML/hash evidence are opaque. Collisions refuse instead of overwriting either spelling.

New owned tag records carry internal `vocabulary: 2`. This distinguishes a current `width: 1.01` fraction from a pre-0.34 `width: 1.01` pixel value; the latter becomes `widthPx: 1.01`. A datasets map is not a tag-record object and is never stamped: `vocabulary` remains a legal authored dataset id.

Two additional binding issues were addressed during selective review. Legacy color slots were enumerated in the lexical order of old region names, which differs after renaming; an internal WeakMap retains the verified old order without adding authored properties. The first focused regression confirmed that authoritative Dataset and chart-data rows are scalar-only, so those values have no S1–S4 field migration. Their trees and hash inputs now remain entirely opaque; rich run/style adaptation applies only to authored table cells. Known generated shape-name paths resolve to the new logical region key while actual native names remain unchanged. Overlay provenance now accepts the new pixel keys; the original implementation omitted this validator update.
