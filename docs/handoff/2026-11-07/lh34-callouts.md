# LH-34: editable image-local callouts

The v0.34 item is on `codex/lh-34-image-callouts`, separate from LH-16. Schema, shared geometry and both engines are implemented. `image.callouts` is supported only on inline content image payloads (including root image shorthand); reusable asset records, logos, backgrounds and video remain ordinary assets.

Each callout has plain `text` and `x`, `y`, `width`, `height` fractions of the visible picture frame, measured physically from its top-left in every language. Cropping/focus changes pixels beneath the label; no source-pixel tracking is inferred. Known `contain` dimensions anchor inside the visible pixels, excluding letterbox padding; unresolved dimensions use the available composed frame, so hosts should resolve assets before composing. Schema bounds reject invalid numeric/rich/unknown fields, and composition rejects invalid raw inputs. Protruding frames and unreadable text report located overflow without cropping or shrinking words. Body-role text grows and centers in a theme-colored panel, with a 32-em reading measure. See docs/image-treatments.md for the complete contract.

SVG uses real text above the picture's mask/overlay. PPTX uses native panel rectangles and editable measured line boxes, with current native words recovered through topology/boundaries, never old source words. Complete valid picture/panel identities restore fractional frames; changed or incomplete geometry stays ordinary current-native content with findings. Unavailable pixels retain editable labels but do not restore stale callout source metadata. A malformed tag cannot inject old text through frame metadata. Markdown is lossless and image promotion reports dropped callouts.

## Vetoable decisions

Use physical visible-frame fractions, not logical RTL coordinates or source-pixel coordinates. Keep callouts specific to image content rather than promising annotations on every resource slot. Use a plain text string, theme panel and measured line editing without adding a styling sublanguage. Preserve the current native words; do not infer new fractions after dragging panel geometry. All judgments remain vetoable in the owner review. No new layout ID or dependency is introduced.
