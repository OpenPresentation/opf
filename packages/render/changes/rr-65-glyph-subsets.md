RR-65 (output-changing for SVG rendered with a fonts handle; pixels unchanged): each face an SVG embeds as `@font-face` data is cut to the glyphs the slide draws, with HarfBuzz's own subsetter (hb-subset from the pinned `harfbuzzjs`, now a dependency), keeping every layout feature so the browser shapes it exactly like the whole face. Over the 127 core example decks an office-pack slide falls from 2.4 MB to 59 KB on average (base pack 530 KB to 73 KB), and 147 example slides draw pixel-identically in a browser. The Node `loadFonts` handle subsets by default; a browser handle does when given `subsetWasm` (the host's copy of `harfbuzz-subset.wasm`). Only faces whose license allows a modified version are cut: bundled faces whose names contain no Reserved Font Name and whose fsType allows subsetting; Carlito, Raleway, Lora, Playfair Display, PT Serif, Merriweather Sans, Source Sans 3 and host faces stay whole. `subsetFonts: false` embeds whole faces. `renderDeckHtml` with `fontMode: "shared"` embeds each face once for the page, cut to the characters all of its slides draw (opf-render#163).
