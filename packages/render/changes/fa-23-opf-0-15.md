FA-23 (breaking, OPF 0.15, requires core 0.15; output-changing for slides with images): the renderer is a library that registers no catalog, and pictures are image backgrounds or image blocks. Removed outright, no aliases:
    - Catalogs: every entry point (`renderSvg`, `renderSlideSvg`, `resolvePresentation`, the font loaders' `renderOptions`, `/player`, `<opf-deck>`) takes core's `catalogs: Catalog[]` and passes it unchanged to `resolveSlideContext`, `resolveScriptFonts` and the boundary `validate`. `catalogSources`, the `catalogs: { <kind>: records }` shape and the renderer's own source lookup and bundled fallback are gone; hosts register `defaultCatalog` from `@openpresentation/opf/catalog` themselves. `strictReferences: true` throws `OPFRenderError` `unresolved-reference` (`details.diagnostics`) instead of falling back. A malformed `catalogs` option throws core's `OPFCatalogsOptionError` (`invalid-catalogs`), and an undeclared prefix (`foo:id`) fails the boundary check as `invalid-opf` (`opf/undeclared-catalog`). A reference that resolves nowhere reports core's `unresolved-reference` diagnostic (replacing `unresolved-layout`, `unresolved-theme`, `unresolved-color-scheme` and `unresolved-font-scheme`) and draws with core's engine defaults; `engineDefaults` is now `{ theme, colorScheme, fontScheme, chartType }` from core's `ENGINE_DEFAULT_*`. `chart.type` is core's `CHART_TYPES` vocabulary, so the preview no longer maps `donut` to `doughnut`.
    - Image backgrounds draw from `geometry.backgroundImage`: canvas colour (the colour scheme's default slide background, now painted under every image background), picture (`cover` with `focus`, `contain`, `stretch`, or `tile` at the picture's intrinsic size; `recolor` and `opacity` on the pixels only), then the overlay (whole slide or edge band). `alt` is the accessible name; without it the picture is `aria-hidden`. An unresolved source keeps the placeholder at the background's opacity.
    - Image blocks draw from `item.image`: frame, fit (`stretch` is new), focus, shape mask, border, opacity, recolor (grayscale, duotone) and overlay, with the outlines and paint order `design.slideImage` used, and placed blocks at their edge band. The slide-image layer (`renderSlideImage`, `data-opf-slide-image*` trace attributes) and every `design.imageFill` and `image-bleed` path are removed; the overlay trace attribute is `data-opf-image-overlay`. The 15 pptx.gallery image treatments written as image blocks and backgrounds draw the same pixels as their 0.14 slideImage renders (`test/image-treatments.mjs`). Image blocks without `fit` take `design.imageFit`, default `cover` (0.14's default fill was fit). Golden changes: `test/golden/notes/FA-23.md`.
