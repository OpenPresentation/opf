FA-30 (attribute-only, no pixel change; SVG bytes change): the slide SVG is a labelled container (`role="group"`, `aria-roledescription="slide"`, `aria-label` = the slide title) instead of `role="img"`, which made every text node inside presentational, so a screen reader heard only the title. Titles, body text, lists, quotes, metrics, table cells, captions, footnotes and furniture text are now reachable, in painted order. Purely decorative drawing (backgrounds and overlays, card frames, table cell fills and borders, dividers, timeline markers, watermarks) carries `aria-hidden="true"`, and a picture with `alt: ""` (image block, background image or furniture picture) is hidden instead of `role="img"` with an empty label; a header or footer picture without `alt` is hidden rather than announced as "Image". `prepareSlideSvg` also removes the root's `aria-roledescription`, so the deck element, the player and `renderDeckHtml` still announce one slide container.
