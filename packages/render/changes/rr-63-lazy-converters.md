RR-63 (breaking install contract, 0.x minor; rendered output is byte-identical, every golden and the PNG and PDF bytes unchanged): the heavy pieces are optional peer dependencies loaded on first use, so an SVG-only install no longer pulls the PDF and PNG converters or the Node font files. `pdf-lib` (19.5 MB), `@resvg/resvg-js`, `sharp` (and its libvips) and every `@expo-google-fonts/*` package (the `base` and `office` packs' Roboto, Roboto Mono, Arimo, Caladea, Cousine, Gelasio, Tinos and the Noto Sans fallback, 13.4 MB for Noto Sans alone) move from `dependencies` to `peerDependencies` marked optional (devDependencies pin them for tests); `fontkit`, `bidi-js` and `pako` stay, because text measurement, the layout and the vector PDF writer use them. Install what you export: `npm install @resvg/resvg-js` for PNG (plus `sharp` for WebP and rotated JPEG pictures), `sharp` for pictures in a vector PDF, `pdf-lib` for `mode: "raster"`, and the font packages of the pack you load (README, "Install"). An export that needs a converter that is not installed rejects with `OPFRenderError` code `converter-missing` (`details.package`, `details.install`); it replaces `png-renderer-unavailable` and `pdf-writer-unavailable` for a missing resvg or pdf-lib, and a vector PDF with a picture no longer skips the picture with `pdf-image-skipped` when `sharp` is absent. `loadFonts` and `copyPreviewFonts` name every font package the pack needs and the `npm install` command in one `font-resource-unavailable` error. New entries `@openpresentation/opf-render/png` (`svgToPng`) and `/pdf` (`svgToPdf`) sit beside `/svg`; the root still exports all four functions, and `/player`, `/element` and `/export-browser` are unchanged (there is no `/html`: it would duplicate `/element` and `/player`). `/export-browser` imports no converter: its raster-mode PDF takes the pdf-lib module as the new `pdfLib` option instead of importing it, so a browser bundle holds no PDF library, and `npm run build:browser-check` asserts that `/svg`, `/fonts-browser`, `/export-browser`, `/player` and `/element` bundle no converter, Node font loader or font package.
