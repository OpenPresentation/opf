RR-54 (needs core with `resolveChartData`, opf#376; an older core keeps the previous behaviour): the preview draws chart and table data the way core resolves it. Every chart path (the catalog charts, the chartex constructs, the legacy sketch) reads `resolveChartData`, so inline `columns` given as `DataColumn` objects, `{ "dataset": "<id>", "fields": [...] }` references to the top-level `datasets` map, and `chart.mapping` (category, scatter X and series chosen by column name) all plot, and a `DataColumn` header labels its series with its `name`. Numbers follow core's strict `chartNumber`: `"12%"`, `"(5)"` and `"Q1"` are gaps and `"1e6"` is 1000000 (the preview read numbers with its own lenient rule before; hex strings such as `"0x10"` were numbers there and are gaps now). A column's number `format` shapes the data labels of its series and the value-axis tick labels (the first plotted series' format, as Excel does for a source-linked axis; the scatter X axis follows the X column; percent axes and pie percent labels stay percent). A chart or table that uses none of the new fields draws byte for byte as before. A dataset chart draws exactly the inline chart and reports its authored chart path (`slides.N.chart`) for every part; a chart with `mapping` reports the authored column index of each plotted column. Table cells draw core's formatted display text (a body cell's `format` wins over its column's), measured by the shared layout, and a dataset table draws exactly its inline table. A formatted horizontal axis (horizontal bars, the scatter X axis) keeps its first and last tick labels inside the chart, and the legacy sketch plots a gap as nothing (a numeric-looking label such as "2020" is no longer read as the value of a gap). A `ChartDataSource` still draws the "No chart data" placeholder. `test/chart-table-data.mjs` covers strict parsing, formatted labels, ticks and cells, dataset equivalence, mapping, scatter X, DataColumn headers and trace paths.
