# Diagrams: the `diagram` content kind

Core gains a `diagram` payload (Mermaid source drawn by pele in the deck's fonts and colors). No existing slide draws differently: the moves below are inputs of the baselines, not drawings.

## Template baseline (`layout-templates-rr96-color-variants.json`)

`node test/layout-template-goldens.mjs --update`, reviewed, then `--promote`d. 0 of 468 slides changed; only the source digest moved. The digest covers the layout records, and the regions of ten gallery layouts that hold a figure now list `diagram` last in `accepts` (`chart`, `chart-beside`, `image`, `image-beside`, `hero`, `comparison`, `two-column`, `three-column`, `process`, `timeline`). Binding takes the first accepted kind a block matches, and no template sample holds a diagram, so every slide composes and draws as before. The PPTX export keeps every layout placeholder type: a diagram never binds to a placeholder, so it is left out of the type (`placeholderType`).
