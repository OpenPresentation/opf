# LH-186: change the layout before shrinking text

A paragraph, list or table set more than one step of the type scale under its role size now tries the arrangements that keep it larger before it shrinks: list columns for a long plain list, and LH-83's automatic grid for a template slide. The guarded rule `layout-first` keeps a change only when the body ends at least as large as before and nothing overflows.
