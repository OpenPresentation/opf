# Plain text whitespace raster review

The candidate retains scalar spaces, tabs, nonbreaking prose tokens, blank lines and CR/LF/CRLF source boundaries. SVG preserves whitespace and uses explicit tab positions. Measured scalar text uses geometric precision and accepted horizontal advances, with the same scoped intrinsic-correction check used for rich text. These advances may scale glyphs horizontally; they are not raw font-equivalence evidence. Estimated wrapping and tab advances remain approximate.

The exact predecessor renderer `c92198b0d0acc94892385a8594fe2879461d64b0` with the retained core candidate tarball reproduces the complete accepted rich-flow baseline. `report.json` records that candidate hash and source evidence. The corpus remains 126 decks / 805 slides with the same source digest. There are 279 changed slides and 526 identical hashes. All 35 paired sheets were visually inspected, together with all six full-size before/after pairs. Spacing, wrapping and alignment changes match source preservation; no new clipping was observed in that review. Sparse layouts, unresolved images/data, missing nested marker glyphs, low contrast and general visual quality remain separate work.

The new `test/golden/opf-examples-png.source-whitespace.sha256.json` is a distinct regression checkpoint. Historical baselines and the initial failing gate remain retained. The browser evidence separately checks 24 presentation cases / 48 title/body fields on Node 20 and 24. It checks exact source reconstruction, explicit tab coordinates and measured advances under the unchanged 0.1px gate, with intrinsic correction bounded to 0.1% of width plus 1/64px. All four complete browser fixture screenshots were inspected. This is not native Office acceptance.
