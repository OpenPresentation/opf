# Shared furniture visual regression review

On September 14, 2026, Node 24.21.0 regenerated all 805 slides from 126 decks.
The archived Node 24 predecessor reproduced the accepted timeline baseline
exactly. The furniture candidate uses the identical source digest and changes
657 slides; 148 remain byte-identical. The first local and CI raster failures
are retained rather than overwritten.

All 83 paired contact sheets in `review-index.json` were visually inspected,
covering every changed slide. Seven controls were also rendered and viewed at
their original size on both sides; their SVG/PNG hashes and observations are in
`acceptance.json`. The review accepts the candidate as a regression baseline,
not as blanket design-quality, browser, font, or native PowerPoint acceptance.

Observed changes are consistent with shared furniture layout: labels honor the
readability floor instead of a fixed 13px size; header/footer bands reserve body
space; aligned labels keep their zones; generated section and slide numbers
remain visible. Body cards, tables, charts, code and timelines adjust within the
remaining area. No new clipping, furniture/body collision, or missing rendered
content was observed in the paired review. The Pine County organization label
now wraps onto two readable lines. Its full-size control retains the complete
body and attribution with separation from the larger footer band.

Existing unresolved-image placeholders, watermark opacity, unsupported/no-data
chart messages, sparse template composition, and some dense body arrangements
are present on both sides. They are not fixed or certified by this baseline.
The dark header/footer control retains the same unresolved logo rectangle and
watermark text; the low-opacity watermark was checked in both SVGs after its
second line was difficult to distinguish in the raster view.

`test/golden/opf-examples-png.furniture.sha256.json` is promoted only after this
review. The timeline baseline remains unchanged. Native Office/font acceptance,
including the existing tab drift and image-opening gates, remains outstanding;
no registry package publication or native automation is part of this review.

## Reproduce

Use Node 24, this repository's locked dependencies, the core repository's pinned
pnpm, and the coordinated furniture source graph. `binding.json` records the
source refs, archive hashes, lock hashes, and generated runtime file hashes.
The predecessor is built from its own archived source; dependency tools are
reused from the locked local installations. No previous-machine artifact is
required.

Run `node test/furniture-review.mjs prepare` into a new output directory (set
`OPF_FURNITURE_REVIEW_OUT` if the default already exists), followed by
`node test/furniture-review.mjs sheets`. Preparation first requires the old
runtime to match the timeline baseline, then retains the candidate's expected
failure against that same baseline. Neither command promotes a baseline.
Use `node test/furniture-review.mjs full 'file.opf.json#0'` with an exact key
from the index for full-size controls. The archive refs are pinned in the script;
other dependencies resolve from the locked renderer checkout.

The committed evidence contains the paired sheets, seven full-size pairs,
manifests, source binding and logs. Individual quarter-scale PNGs can be
regenerated by the same commands. `SHA256SUMS.json` covers the retained files.
