RR-59 (output-changing for `full` provenance exports): a full-provenance round trip restores the absence of document-level defaults. `OPF_DOCUMENT_V1.absent` lists the defaults a document leaves to the engine (`$schema`, `name`, `language`, `design.theme`, `design.colorScheme`, `design.fontScheme`, `design.dimensions`), and `fromPptx` leaves each absent while the package still shows the default, so an untouched round trip is deep-equal to the source; a theme colour, slide size, title or run language edited in PowerPoint imports as observed. Every `full` export therefore carries the document and slide tags, also for a document that states nothing else (every other part is byte-identical; `references-only` and `false` are unchanged). Every picture path reports an unresolved source once (opf-pptx#210): a quote photo now emits `unresolved-asset` with its placeholder, so strict export (`--fail-on warning`) gates it; a local image file that cannot be read is an unresolved source (`reason: 'file-unreadable'`, `strictAssets` throws `missing-asset`) instead of failing the whole export with `pptxgen-failed` on any path; and a background picture with alt text no longer reports unreadable bytes twice. See `docs/document-roundtrip.md`.
