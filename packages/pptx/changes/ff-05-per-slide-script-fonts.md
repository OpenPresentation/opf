FF-05 (opf-pptx#168; output-changing only for decks whose slides select different East Asian / complex-script fonts): a slide's own script fonts (a per-slide `design.fontScheme`, slide theme, or inline `eastAsian`/`complexScript`) now reach PowerPoint. The presentation theme is built from the first slide and runs name no `ea`/`cs` (FF-05), so later slides drew their script text in the first slide's fonts with no diagnostic. Each further script profile now gets its own slide master (a copy of master 1 and its layout) whose theme is the presentation theme with that slide's script slots and per-script entry; slides with the same profile share it, run-level `ea`/`cs` stay stripped, and a deck with one profile is byte-identical (976 of 976 corpus decks). The single notes master keeps the presentation theme, so a slide on another master that has notes reports `script-font-notes-not-exported`. Import reports `script-font-not-imported` per slide when a slide master's theme names script fonts the imported slide does not resolve to (only without provenance), and compares the presentation theme with the first slide rather than the deck default. `checkPptxTypefaces` takes `themeScriptsByPart`, resolves theme references through each part's own master, and the inventory lists every theme part (`themeParts`).
