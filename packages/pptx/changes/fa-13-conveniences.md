FA-13: export and import of the small conveniences core adds. `code.highlight` is one native rectangle per run of marked lines between the code panel and the line text boxes (tagged `OPF code N highlight M`, so a band never imports as text and a deleted band loses nothing), the unmarked lines are dimmed, and import restores `highlight` from the code provenance tag. A text `design.watermark` is one native text box per slide (heading font, theme text color at the opacity as text alpha, centered, rotated 30 degrees counterclockwise, tagged `OPF_WATERMARK_V1` with `kind: text`); import restores `design.watermark` from an unchanged box and reports an edited one. `TextRun.code` exports in the design's code family and imports back as `code: true` in an OPF-exported package; `TextRun.lang` exports as `a:rPr lang` (the language's curated OOXML tag, with `altLang`) plus the run's own East Asian and complex-script faces, and import reads a run language that differs from the deck language back into `lang`. The `1:1`, `4:5` and `9:16` presets export as `p:sldSz` 6858000 x 6858000, 6858000 x 8572500 and 6858000 x 12192000 and import back as presets.
