Editor chrome examples

Eight small pages, one idea each. They run the built package from this folder; the guide that explains them is packages/editor/docs/chrome-guide.md.

  • embedlayout: "embed" in a 720 by 420 card, with the deck name shown outside it.
  • viewerlayout: "viewer": read-only, Present and Expand, and a host "Download PPTX" action.
  • fulllayout: "full" with Save and Share actions, guardUnload, Ctrl/Cmd+S and a dirty indicator.
  • own headerNo toolbar: the title, history, counter, design menu and expand button in the page's own header (slots).
  • headlessThe page's own title field and buttons, driven by the handle and its events.
  • react<OpfEditor> with useOpfDeckName and useOpfDirty.
  • element<opf-editor> with an inline deck and an opf-deck-name listener.
  • styledStyling hooks: a dark bar, a serif title, custom icons and a pill-shaped review status.
