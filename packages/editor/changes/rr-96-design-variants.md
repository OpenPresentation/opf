RR-96 (needs core 0.23 for `design.variant`): color variant pickers. New `/design-variants` entry point: `setDesignVariant` and `prepareDesignVariant` set `design.variant` (a background slot `light1`, `light2`, `dark1` or `dark2`, written as the slot name, or `{ background, accents }` when the six accents are reordered; `null` removes it) at the deck or on one slide with `slideIndex`, as one undoable patch, with `clearSlideOverrides` and a `shadowed` list for the slides whose own variant or theme-slot background hides a deck change; `readDesignVariant` reads the own and the effective variant (core's resolution) and `variantSwatches` the four variants as colors built from the deck's own scheme slots, like PowerPoint's Variants gallery; `normalizeVariant` validates. The design controls gain a "Color variant" section (four swatches, "Same as presentation" on a slide, an accent order control and "Reset accent order"); the editor imports core's `normalizeColorVariant`, so it needs core 0.23. The preview and the PowerPoint export read the variant from core's roles.
