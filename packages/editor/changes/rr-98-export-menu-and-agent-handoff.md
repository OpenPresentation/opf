RR-98: `createExportMenu` (`@openpresentation/opf-editor/export-menu`), the Export menu of the playground redesign: a button and a grouped `role="menu"` (Slides: PowerPoint, PDF, SVG, PNG; OPF source: JSON, YAML, Markdown; For an agent) with a mobile bottom-sheet mode (`mode: "sheet"`), `density: "touch"`, `items` to hide groups or formats and `setDisabled(reason)`. PDF, PNG and SVG use `convert`; PowerPoint is injected as `exportPptx(deck, { signal, onProgress })` because the editor does not import `@openpresentation/opf-pptx`; YAML and Markdown use core's `toYaml` and `toMarkdown` and report their notes. Progress, Cancel (an `AbortController`), a success or failure line announced through `aria-live`, and downloads through a Blob link or `onDownload` are built in. `buildAgentHandoff(document, { target, fileName, specUrl, agentGuideUrl })` (`/agent-handoff`) writes the prompt for a coding agent (install the CLI, `npx opf validate`, `npx opf convert`, report, with the exact deck JSON), and `createAgentHandoffDialog` (`/agent-handoff-dialog`) is its modal (target switch, Copy prompt, focus trap). The playground's separate PowerPoint and PDF / PNG / SVG dialogs are replaced by the menu. Styles: `src/styles/export-menu.css` and `src/styles/handoff.css`, `--opf-ui-*` tokens only.
