RR-63 (no breaking change; for opf-render 0.16, whose `pdf-lib`, `@resvg/resvg-js`, `sharp` and `@expo-google-fonts/*` packages are optional peers): `exportDeck` takes a `pdfLib` option, the pdf-lib module (`import * as pdfLib from "pdf-lib"`), and hands it to the renderer's `export-browser` PDF converter for `pdfMode: "raster"`, because that entry no longer imports pdf-lib itself; a raster PDF without it rejects with the renderer's `converter-missing`. The vector PDF, PNG and SVG exports need nothing new. The playground imports pdf-lib for its raster PDF choice. The README lists what to install for each use of the renderer (the canvas and SVG need nothing, `loadFonts` from `/fonts-node` needs the font packages of its pack, Node PNG and PDF need the converters). The tests and the playground build list the renderer's optional peers they load (the Roboto, Roboto Mono, Arimo, Caladea, Cousine, Gelasio and Tinos font packages, and pdf-lib) as devDependencies, so they run against opf-render 0.15 and 0.16. The `@openpresentation/opf-render` peer range is unchanged.
