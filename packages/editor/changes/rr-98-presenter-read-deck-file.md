RR-98: `@openpresentation/opf-editor/presenter` adds `createPresenter` (full screen through the Fullscreen API with a fixed-overlay fallback, slides drawn with the canvas's renderer, fonts handle and catalogs and letterboxed on black, the neighbors drawn ahead; Right, Space, PageDown, Enter, Left, PageUp, Backspace, Home, End, Esc, click zones and touch swipes; hidden slides skipped as the exports skip them; a "03 / 12" counter on pointer move; `onExit(index)` and `onSlideChange(index)`; `role="dialog"`, a focus trap and an `aria-live` announcement), `createPresentButton` (an icon-only "Present" button, title "Present (F5)", styled like the Export trigger) and `bindPresentShortcut` (F5, ignored while typing). `@openpresentation/opf-editor/read-deck-file` adds `readDeckFile(file | { name, text })` (JSON, YAML or Markdown by extension, with fallbacks, through core's `fromYaml` and `fromMarkdown`; returns `{ document, format, name, findings }` and throws a typed `DeckFileError`) and `DECK_FILE_ACCEPT` for `<input accept>`. The example playground has a Present button next to Export, and its Import file tab and drop zone read `.yaml`, `.yml` and `.md` through `readDeckFile`. The styles are `src/styles/presenter.css`, in `styles.css`.
