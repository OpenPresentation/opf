RR-54: the data grid edits chart and table data in core's RR-54 contract (opf#376; needs a core with it). A chart column or table header that is a `DataColumn` (`{ name, format }`) shows its name and keeps its number format through rename, insert, delete, move and paste. A per-column number format field sets or clears the format (a string header becomes `{ name, format }` and back), validated with core's `numberFormatError` and explained inline (`prepareGridColumnFormat`, `setGridColumnFormat`, `columnFormatError`). A chart or table that shows a shared top-level dataset (`{ dataset, fields? }`) is edited at `/datasets/<id>`: edits map back to the dataset's own columns through `fields`, hidden columns keep their data, a column added while `fields` is set goes to the dataset and to `fields`, renaming a column updates every `fields` and `mapping` that names it, the status line says how many items share the dataset, and "Use a copy of the data" gives the item its own inline copy (`detachGridDataset`). A chart's "Chart columns" panel sets the category, X (scatter only) and series columns as `chart.mapping` (`describeChartMapping`, `prepareChartMapping`, `setChartMapping`). `prepareDatasetImport` and the playground's "Store as a shared dataset" import data as `datasets.<id>` like `opf import-data --dataset`. Chart cells follow core's `chartNumber`: text that is not a number is refused with the reason and a stored string that it reads as a gap is flagged. Find and replace searches dataset text, block conversion and chart-type compatibility read dataset charts, and the table panel and `table-options` refuse a dataset table with `table-dataset-backed`. A formatted column shows its numbers as the slide draws them (core's `formatDataNumber`; the cell's raw value is what editing and copy use, and a document without formats looks as before). Dataset and mapped-chart column names are never blank and a new column's name differs from every dataset column, also the hidden ones; styling or merging a `DataColumn` header and turning a table's header off keep the document valid; switching a chart to a type without an X axis removes `mapping.x`; a format typed for one column stays on that column; and the Import data dialog starts with a free dataset id. With a core that predates the data contract the grid hides the format field and Chart columns panel and reports a reason instead of throwing (`supportsChartTableData`). Every edit is one undoable patch, and a document without the new fields behaves as before.
