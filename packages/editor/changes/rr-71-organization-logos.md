RR-71 (breaking, 0.18; needs core 0.18): logos live on the organization, so the logo controls follow. `setLogoVariant`, `prepareLogoVariant`, `readLogoVariants`, `LOGO_VARIANTS` and the `organizationLogo` design option are gone with no alias; `setOrganizationLogo(editor, shape, source, { background, organization })` (with `prepareOrganizationLogo`, `readOrganizationLogo`, `listOrganizations`, `LOGO_SHAPES` and `LOGO_BACKGROUNDS`) edits `organization.logo`: one image for every shape (`"all"`), or each of `full`, `stacked`, `icon` and `wordmark` for both backgrounds, light only (`onLight`) or dark only (`onDark`). The `logo` design option is now the `design.logo` override (`null` for the primary organization's, `false` for none, or a `var:organization.<id>.logo.<shape>` reference, or `{ organization, shape }` to write one; `readLogoChoice`, `parseLogoReference`, `logoReference`). The header and footer zone `logo: true` field is gone (refused with a message that says what to write); `insertZoneLogo(editor, which, zone, { shape, organization })` (and `prepareZoneLogo`) makes the zone's `image` the reference `var:organization.logo.icon`. The design panel's logo section edits the organization's shapes and backgrounds (for the organization you choose), adds a "Which logo to draw" picker (Primary organization, a named organization and shape, or None), and gives the zone image an "Insert logo" action with a shape choice and, for several organizations, an organization choice; the zone's "Show the logo" toggle is removed. The template panel lists the organization logo built-ins (kind `image`, scope `slide`) read-only as `var:` references and leaves them out of the text-token insert list. Design warnings follow the new rules (a zone image or `design.logo` naming a logo no organization has, picture bullets without an icon logo). The preview and `composeSlide` draw `resolveSlideContext(...).slide`, so a logo reference shows the `onLight` or `onDark` artwork that suits each slide's background. The Review panel's alt-text fix (`setReviewAltText`, `markDecorative`, `altTextPatch`, `currentAltText`) keeps a logo reference a whole-field string and writes the alt on the organization logo asset(s) it draws (light and dark), or refuses a reference that names no logo (`unresolved-logo-alt`).
