# Native acceptance fixture sources

These are source inputs, not generated PowerPoint or native acceptance evidence.

- `wide.png` is the synthetic 120×60 image generated by `opf-pptx/test/fixtures/images/generate.py`. The generator creates colored rectangles and an ellipse from code; it uses no external image. The copy preserves the existing tracked fixture bytes.
- `chartex-fallback-main.json` comes from `opf-pptx/test/fixtures/chartex-fallback-main.json`. It contains the nine reviewed chart source decks and their fallback archive digests. The native suite keeps all nine in fallback, auto and native modes, including the explicit native multi-series Pareto rejection. A separate positive single-series Pareto source is defined in `chart-modes.mjs`.
- `features/*.opf.json` and `feature-inputs.json` preserve the eight source documents and review metadata from the RR-20 T31 source packet adapter. The four gallery-site examples retain the documented explicit Roboto font overlay for permissive measured export. `fixture-source.mjs` verifies each source digest before generation.
- `actions/layout-title-auto.json` and `actions/furniture-inherited.json` preserve the reviewed bounded action plans. Every other primary case receives an explicit empty plan.
- The six-slide table-color payload is defined in `table-colors.mjs` from the tracked PPTX native table-color control. It requires its dedicated native worker; the generic worker's three-slide limit remains unchanged.

The generator resolves engines from the caller's installed consumer and records its supplied source identity. The runner verifies that identity and owns the final suite manifest and seal. No source revision or temporary checkout path is embedded here.
